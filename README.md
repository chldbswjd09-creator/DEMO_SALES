# 매출·광고 성과 분석 대시보드 — 포트폴리오 DEMO

이커머스 **일별 매출 / 주별 추이 / 플랫폼별 비중**과 **Meta 광고 성과(ROAS·UTM·증분 ROAS)**를
한 화면에서 기록·분석하는 대시보드의 **포트폴리오 데모** 버전입니다.

> ⚠️ **데모 안내** — 화면의 모든 수치는 **가상 샘플 데이터**이며 실제 매출·광고비·고객 정보가 아닙니다.
> 로그인/비밀번호가 없고, 외부 서버·데이터베이스로 어떤 데이터도 전송하지 않습니다.
> 입력·수정한 내용은 **접속한 브라우저(localStorage)에만** 저장됩니다.

## 주요 기능
- **2개 가상 브랜드 전환** — `A 커머스`(멀티채널: 독립몰·카페24·쿠팡·네이버 2채널)와 `B 커머스`(단일 네이버 + Meta 광고 성과 중심). 데이터는 브랜드별로 완전히 분리.
- **일별 매출** — KPI 카드, 채널별 비중 도넛, 일별 매출·ROAS 콤보 차트, 상세 표(셀 인라인 편집).
- **주별 분석** — 주 단위 집계·비교, 증분 ROAS / Meta 성과 추이.
- **플랫폼별** — 채널별 매출 구성 분석.
- **엑셀 다운로드** — 현재 브랜드의 일별/주별 데이터를 `.xlsx`로 내보내기(클라이언트에서 생성).
- **샘플 초기화** — 사이드바 하단 버튼으로 가상 데이터를 새로 생성.

## 기술 구성
- 순수 **HTML / CSS / JavaScript** 단일 파일(`index.html`) — 빌드 과정 없음.
- 차트: **Chart.js** + datalabels 플러그인, 엑셀: **SheetJS(xlsx)** — 모두 CDN 로드.
- 저장소: 브라우저 **localStorage** (브랜드별 키). 서버·DB·환경변수 없음.

## 로컬에서 보기
`index.html` 파일을 브라우저로 열기만 하면 됩니다(별도 서버 불필요).
```bash
# 또는 간단한 정적 서버로:
npx serve .
```

## 배포 (정적 호스팅)
환경변수 없이 **정적 파일만** 올리면 됩니다. 예) Netlify
1. 저장소를 연결하거나 폴더를 드래그 앤 드롭
2. Build command 없음 / Publish directory `.` (`netlify.toml`에 설정됨)

## 원본과의 차이(데모화하며 제거/변경한 것)
- 공용 비밀번호 **로그인·세션 쿠키·3시간 유휴 로그아웃** 제거
- **서버리스 함수**(`/api/auth`, `/api/revenue`, `/api/status`)와 **Upstash Redis** 연동 전부 제거
- 실제 브랜드명·매출·광고비·고객 정보 제거 → **가상 샘플 데이터**로 대체
- 데이터 저장을 서버 공용 저장소 → **브라우저 localStorage**로 변경
- 화면 상단에 **포트폴리오 DEMO** 배너 표시
